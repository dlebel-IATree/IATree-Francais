# L'Arbre de l'audit interne

Outil interactif et gratuit qui présente la taxonomie des missions d'audit interne, inspirée de l'Arbre de la fraude de l'ACFE.

- **3 branches** : Assurance non-TI, Assurance TI, Conseil
- **50 familles · 266 catégories · 718 types de missions**
- Pour chaque type : description, quand l'utiliser, cadres et critères
- Recherche par mot-clé, liens directs vers chaque fiche, affiches PDF
- Téléchargement du contenu (Markdown, CSV, JSON) pour l'utiliser avec votre assistant IA (LLM)

👉 **Ouvrir l'outil** : voir le lien dans la section « About » de ce dépôt.

Les branches Assurance TI et Conseil sont des premiers jets, à valider avec des praticiens. Vos commentaires sont les bienvenus.
